# Ring Battery Monitor

Public support, privacy policy and terms for the independent iOS app.

## TestFlight beta

All beta features are available without an app subscription, purchase or trial countdown. The app does not charge testers automatically. The labelled sample-data demo also works without an Oura account and includes example battery observations.

## Requirements

- iOS 26 or later and a compatible Oura ring and account for your own battery data.
- **Oura Ring Gen3 and later require an active Oura Membership** for API access, including during this beta. Oura provides this membership; it is not included in beta access. [Oura’s API requirements](https://support.ouraring.com/hc/en-us/articles/4415266939155-The-Oura-API).
- Gen2 does not require Oura Membership, but this app’s access to Gen2 battery data has not been verified. Compatibility still needs a real Gen2 test.

Any future release subscription will be introduced separately with updated terms and an explicit purchase choice. Beta participation does not create a payment obligation.
